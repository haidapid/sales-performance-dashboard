# Sales Performance Dashboard

An interactive sales dashboard built with Microsoft Power BI to analyze sales performance, monitor key metrics, and identify business insights through data visualization.


## Dashboard Preview

![Sales Performance Dashboard](Sales%20Performance%20Dashboard.jpg)


## Project Overview

This project presents a sales performance dashboard designed to provide an overview of business performance through key performance indicators, product analysis, sales channel distribution, geographic sales distribution, and monthly sales trends.

## Objectives

- Monitor key sales performance indicators.
- Analyze product sales performance.
- Evaluate sales target achievement.
- Compare sales contributions across different channels.
- Track monthly sales trends.
- Explore sales distribution across locations.

## Dashboard Features

- **Sales KPIs:** Overview of sales, orders, profit margin, and profit.
- **Product Analysis:** Comparison of sales performance across products.
- **Target Achievement:** Monitoring progress toward sales targets.
- **Sales Channel Analysis:** Distribution of sales across different channels.
- **Geographic Analysis:** Visualization of sales distribution by location.
- **Monthly Trends:** Analysis of sales performance over time.

## Tools & Technologies

- Microsoft Power BI
- Data Visualization
- Sales Performance Analysis
- Business Intelligence

## Key Insights

The dashboard enables users to explore sales performance, compare product contributions, monitor target achievement, and identify trends across sales channels and locations.

Specific findings can be added after analyzing the underlying data.
